# แผนที่อ่อนไหวดินถล่มน่าน

เว็บแผนที่ของโครงงานวิเคราะห์พื้นที่อ่อนไหวต่อแผ่นดินถล่ม จังหวัดน่าน
ใช้ MapLibre GL JS แผนที่ฐานคือ Esri World Imagery

## วิธีเปิดดู

- **บนเว็บ (แนะนำ):** นำทั้งโฟลเดอร์นี้ไปวางบนบริการโฮสต์เว็บ เช่น GitHub Pages แล้วเปิด `index.html`
- **บนเครื่อง:** ดับเบิลคลิก `index.html` ได้เลย ต้องต่ออินเทอร์เน็ตเพื่อโหลดภาพดาวเทียมและฟอนต์

## อยากแก้อะไร ให้เปิดไฟล์ไหน

| สิ่งที่ต้องการแก้ | ไฟล์ |
|---|---|
| ข้อความทุกอย่างบนเว็บ (ชื่อเว็บ เมนู ปุ่ม หัวตาราง คำอธิบาย) | `js/text.js` |
| ชื่อชั้นข้อมูล สีสัญลักษณ์ ชื่อฟิลด์ใน popup | `js/layers-config.js` |
| ชั้นที่เปิดตอนเริ่ม ลำดับการวาด ความทึบ มุมเอียง 3 มิติ ชื่อและสีของระดับ | `js/settings.js` |
| สี ขนาดตัวอักษร ขนาดแผง | `css/style.css` (สีหลักอยู่ในบล็อก `:root` ด้านบนสุด) |
| โลโก้ | แทนที่ไฟล์ใน `assets/` ด้วยชื่อเดิม |
| โครงหน้าเว็บ ตำแหน่งปุ่ม | `index.html` |

### ตัวอย่าง: เปลี่ยนชื่อเว็บ

เปิด `js/text.js` หาบรรทัด

```js
title: 'แผนที่อ่อนไหวดินถล่มน่าน',
```

แก้ข้อความในเครื่องหมายคำพูด บันทึก แล้วรีเฟรชหน้าเว็บ
ห้ามลบเครื่องหมาย `'` และ `,` และห้ามลบคำในวงเล็บปีกกา เช่น `{n}` เพราะระบบจะเติมตัวเลขให้ตรงนั้น

## โครงสร้างโฟลเดอร์

```
index.html              โครงหน้าเว็บ
css/style.css           หน้าตา
assets/                 โลโก้ 3 รูป
vendor/                 ไลบรารีแผนที่ MapLibre GL JS (ไม่ต้องแก้)
js/
  text.js               ข้อความทั้งหมด
  settings.js           ค่าตั้งของแผนที่
  layers-config.js      รายการชั้นข้อมูลและสัญลักษณ์ (จากไฟล์ .lyrx)
  core.js               ตัวแปรกลางและการโหลดข้อมูล
  geo.js                สูตรคำนวณ: พิกัด UTM ระยะทาง พื้นที่
  map.js                แผนที่ ชั้นข้อมูล popup ทิศเหนือ มุมมอง 3 มิติ
  measure.js            เครื่องมือวัดระยะทางและพื้นที่
  ui.js                 แผงสรุป คำอธิบายสัญลักษณ์ แผงชั้นข้อมูล ค้นหา แถบสถานะ
  pages.js              หน้าภาพรวม และหน้าข้อมูลแผนที่
  main.js               ผูกปุ่มกับฟังก์ชัน และเริ่มการทำงาน
data/
  core.js               ข้อมูลที่โหลดตอนเปิดเว็บ และสถิติสรุป
  rasters-index.js      ดัชนีชั้นราสเตอร์
  dem.js                แบบจำลองความสูงสำหรับมุมมอง 3 มิติ
  layers/               ชั้นเวกเตอร์ขนาดใหญ่ (โหลดเมื่อเปิดชั้น)
  rasters/              ชั้นราสเตอร์ 10 ชั้น (โหลดเมื่อเปิดชั้น)
```

ไฟล์ใน `js/` โหลดตามลำดับที่เขียนไว้ท้ายไฟล์ `index.html` ไฟล์ทั้งหมดใช้ตัวแปรกลางชื่อ `App`

## ที่มาของตัวเลข

- สถิติในตารางสรุปคำนวณจากข้อมูลเต็มความละเอียดก่อนย่อลงเว็บ เก็บอยู่ใน `data/core.js`
- สถิติรายตำบลและรายอำเภอคิดตามระดับของผลการศึกษา (AHP)
- เครื่องมือวัด: ระยะทางคำนวณบนทรงรี WGS84 (สูตร Vincenty) พื้นที่คำนวณบนพิกัด UTM

## ข้อจำกัด

- ชั้นอาคารแสดงเป็นจุดกึ่งกลางอาคาร ไม่ใช่รูปร่างอาคาร
- ชั้นราสเตอร์แสดงที่ความละเอียดราว 60 เมตร และคลิกดูค่าไม่ได้
- ภูมิประเทศ 3 มิติมาจาก DEM ของโครงงาน นอกเขตจังหวัดเป็นค่าที่เกลี่ยให้เรียบ ไม่ใช่ความสูงจริง
